# Elisa Castañón García-Rovés

**MRI Physicist | Low-Field MRI | Medical Imaging | Experimental R&D**

PhD physicist currently working on portable low-field MRI at the MRI-Lab, Institute of Instrumentation for Molecular Imaging (i3M, CSIC–UPV), Spain.

My current research combines MRI system characterisation, image acquisition and processing, medical-imaging data management, quality control, and clinical validation of portable low-field MRI systems.

I use Python and MATLAB as research tools for MRI data processing, quantitative analysis, workflow development, and validation.

## Current MRI development work

Most of my current development work is maintained within the MRI-Lab GitHub organisation and includes:

- **TolkaDicomTags** — Python tools for DICOM metadata harmonisation and validation of low-field MRI datasets.
- **LaFe2025_VIEWS_DB** — Data preparation, quality-control, and analysis workflows for a clinical study comparing portable low-field and clinical high-field knee MRI.
- **Bergmann_2026_DB** — Data preparation and validation workflows for a comparative low-field/high-field MRI study.

These repositories form part of ongoing collaborative research projects and are maintained within the institutional MRI-Lab GitHub organisation.
